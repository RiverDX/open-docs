## 目标

用户可以更新任务的状态，从 `todo` 到 `in-progress`，再到 `done`。

## 验收标准

- [ ] 可以把任务从 `todo` 改成 `in-progress`
- [ ] 可以把任务从 `in-progress` 改成 `done`
- [ ] 可以把任务从 `todo` 直接改成 `done`
- [ ] 改成无效状态会报错
- [ ] 状态更新后，`getTasks()` 会看到新状态

## 实现指南

1. 复用 Issue 1 的代码结构
2. 封装状态机逻辑在 `Task` 模块内
3. 通过公开接口测试
